| mRS | 状態 |
|---|---|
| **0** | まったく症候がない |
| **1** | 症候はあっても明らかな障害はない：日常の勤めや活動は行える |
| **2** | 軽度の障害：発症以前の活動がすべて行えるわけではないが、自分の身の回りのことは介助なしに行える |
| **3** | 中等度の障害：何らかの介助を必要とするが、歩行は介助なしに行える |
| **4** | 中等度から重度の障害：歩行や身体的要求には介助が必要である |
| **5** | 重度の障害：寝たきり、失禁状態、常に介護と見守りを必要とする |
| **6** | 死亡 |
