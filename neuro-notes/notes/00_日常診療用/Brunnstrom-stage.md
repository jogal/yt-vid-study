## 上肢
| Stage | 所見 |
|---|---|
| **Ⅰ** | 随意運動なし（弛緩性麻痺） |
| **Ⅱ** | 筋緊張が高まり連合反応として共同運動が不随意に出現 |
| **Ⅲ** | 筋緊張がさらに高まり、共同運動が随意的に出現 |
| **Ⅳ** | 筋緊張が減少し始め、共同運動から逸脱した分離運動が出現<br>1. 手背を腰の後方につけることが可能<br>2. 肘関節を伸展したまま上肢を前方から頭上まで上げることが可能<br>3. 肘関節を90°屈曲したまま、前腕を回内・回外することが可能 |
| **Ⅴ** | 筋緊張がさらに減少して、共同運動からさらに逸脱した分離運動が可能<br>1. 肘関節を伸展かつ前腕を回内したまま、上肢を横水平位まで上げることが可能<br>2. 肘関節を伸展したまま、上肢を前方から頭上まで上げることが可能<br>3. 肘関節を伸展したまま、前腕を回内・回外することが可能 |
| **Ⅵ** | 筋緊張の亢進がなくなり、分離運動を自由に行うことが可能。協調運動を正常に行うことが可能 |

## 手指
| Stage | 所見 |
|---|---|
| **Ⅰ** | 随意運動なし（弛緩性麻痺） |
| **Ⅱ** | 手指の屈曲が最小限の範囲で随意的に可能 |
| **Ⅲ** | 手指の集団屈曲が可能。随意的な手指の伸展はできないが、反射による伸展ができることがある。鈎形握りができることがあるが、離せない |
| **Ⅳ** | 手指の伸展が狭い範囲で半ば随意的に可能。横つまみが可能であり、母指の動きでそれを離すことも可能 |
| **Ⅴ** | 手指の集団伸展が可能。対向つまみ、円柱握り、球形握りが可能であるが、拙劣で実用性が低い |
| **Ⅵ** | 手指の伸展が全可動域にわたって随意的に可能。手指の分離運動も可能であるが、健側よりは多少拙劣である。すべてのつまみが上手にできる |

## 下肢
| Stage | 所見 |
|---|---|
| **Ⅰ** | 随意運動なし（弛緩性麻痺） |
| **Ⅱ** | 筋緊張が高まり、下肢の随意的な運動が最小限の範囲で出現 |
| **Ⅲ** | 筋緊張が最大となり、下肢屈曲もしくは伸展の共同運動が出現。座位もしくは立位で、股・膝・足関節の屈曲が可能 |
| **Ⅳ** | 1. 座位で足を床上で滑らせながら、膝関節を90°以上屈曲することが可能<br>2. 座位で踵を床につけて膝関節を90°屈曲したまま、足関節の背屈が可能 |
| **Ⅴ** | 1. 立位で股関節を伸展したまま、膝関節の屈曲が可能<br>2. 立位で足を少し前方に出して膝関節を伸展したまま、足関節の背屈が可能 |
| **Ⅵ** | 座位もしくは立位で、骨盤挙上による範囲をこえて股関節の外転が可能。座位で、内側・外側ハムストリングスの交互収縮により、足関節の内がえし・外がえしを伴った下腿の内旋・外旋ができる |
