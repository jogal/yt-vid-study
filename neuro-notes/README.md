# Neuro Notes — 脳神経内科 診療ノート

診療中にすぐ引ける、自分専用のノートサイト。
ノートは Markdown ファイルで書き、ビルドすると **スマホでもPCでも使える、オフライン対応の Web アプリ（PWA）** になる。

- 🔎 **即時検索**：タイトル・別名（略語）・タグ・本文を横断。全角/半角、カタカナ/ひらがな、「・」「-」の有無を区別しない（`ギランバレー` → Guillain-Barré症候群、`rtpa` → rt-PA用量）
- 📴 **オフライン**：一度開けば電波がなくても全ノートを検索・閲覧できる（ホーム画面に追加推奨）
- 🧮 **計算ツール**：rt-PA用量、NIHSS、GCS（結果をカルテ用にコピー可）
- 🔗 **Scrapbox 風リンク**：`[[ノート名]]` でリンク、被リンク（このノートを参照しているノート）を自動表示。未作成のノートへのリンクは赤字の点線
- ⭐ お気に入り・最近見たノート、ダークモード、文字サイズ切替（端末ごとに保存）

## ディレクトリ構成

```
neuro-notes/
├── notes/                    ← ノート本体（ここだけ編集すればOK）
│   ├── 00_日常診療用/
│   │   ├── NIHSS.md
│   │   └── rt-PA用量.md …
│   ├── 03_脳血管障害/ …
│   └── 90_メモ/
├── build.py                  ← サイト生成
├── config.yaml               ← サイト名・編集リンクの設定
├── tools/scrapbox_import.py  ← Scrapbox からの取り込み
└── web/                      ← 画面（HTML/CSS/JS/Service Worker）
```

- フォルダ名がカテゴリになる。先頭の数字（`03_`）は並び順用で、表示では消える。
- ファイル名は自由（スペースは避ける）。表示名は front matter の `title`。

## ノートの書き方

```markdown
---
title: Guillain-Barré症候群
aliases: [GBS, ギラン・バレー症候群]   # 検索・リンクで使う別名・略語
tags: [末梢神経, 免疫性ニューロパチー]
pin: true          # ホームの「クイックアクセス」に出す（任意）
status: stub       # 書きかけの印（任意）
---
## 診断
- 先行感染から **4週以内にピーク**
- 鑑別は [[CIDP]] を参照          ← ノートへのリンク（別名でもOK）
- #髄液 蛋白細胞解離             ← 本文中の #タグ もタグになる

> [!注意]
> 呼吸筋麻痺に注意。%VC をフォロー。

| 項目 | 値 |
|---|---|
| 表も | 書ける |
```

使える記法:

| 記法 | 内容 |
|---|---|
| `[[タイトル]]` / `[[タイトル\|表示名]]` | 他のノートへのリンク |
| `#タグ` | タグ（前にスペースが必要） |
| `> [!注意]` `> [!ポイント]` `> [!メモ]` | 色付きの囲み |
| ```` ```tool ```` + `rtpa` / `nihss` / `gcs` | 計算ツールを埋め込む |
| `![説明](画像.png)` | 画像（ノートと同じフォルダに置く） |
| `<details><summary>…</summary>…</details>` | 折りたたみ |
| `- [ ] 項目` | チェックリスト |

改行はそのまま改行として表示される（Scrapbox と同じ感覚で書ける）。

## ビルドと確認（PC）

```bash
cd neuro-notes
pip install -r requirements.txt
python3 build.py
python3 -m http.server -d dist 8000   # → http://localhost:8000
```

## スマホで使う（公開とホーム画面追加）

`.github/workflows/neuro-notes.yml` が、ノートを push するたびに自動でビルドして GitHub Pages に公開する。

1. GitHub のリポジトリ → **Settings → Pages → Source** を「**GitHub Actions**」にする（最初の1回だけ）
2. 既定ブランチに push すると `https://<ユーザー名>.github.io/<リポジトリ名>/` に公開される
3. スマホで開いて
   - iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
   - Android（Chrome）: メニュー →「ホーム画面に追加」/「アプリをインストール」
4. 以後はアイコンから起動。電波がなくても使える。ノートを更新すると、次に開いたとき「新しい版があります → 更新する」と出る

### スマホからノートを編集する

各ノート下部の「GitHub で編集」から、GitHub の Web 画面で直接編集→保存（commit）できる。保存すると数分でサイトに反映される。ホームの最下部「新規ノートを作成」からも追加できる。

## Scrapbox から取り込む

1. Scrapbox のプロジェクト設定 → **Page Data → Export Pages** で JSON をダウンロード
2. 変換:

```bash
python3 tools/scrapbox_import.py ~/Downloads/3jonuro-xxxx.json
```

`notes/80_Scrapbox取込/` に Markdown として書き出される（既存ファイルは上書きしない）。ブラケットリンク・太字見出し・インデント箇条書き・`code:`・`table:`・Gyazo 画像・`#タグ` を変換する。取り込んだあとは適切なカテゴリのフォルダへ移動すればOK。

## 注意

- **患者さんの個人情報は絶対に書かない。** リポジトリと GitHub Pages は公開状態（URL を知っていれば誰でも見られる。検索エンジンには載らないよう `noindex` と `robots.txt` は設定済み）。
- 完全に非公開にしたい場合は、Cloudflare Pages + Cloudflare Access（無料・自分のメールアドレスでだけログイン可）に `dist/` を置く方法がある。
- 薬剤の用量・適応は必ず添付文書・ガイドライン・施設プロトコルで確認すること。
