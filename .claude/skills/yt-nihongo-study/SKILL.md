# yt-nihongo-study — YouTube 動画から日本語学習ノートを作る

YouTube 動画の URL を1つ受け取り、字幕とメタデータを取得して、
プレゼンテーションや解説の**要点を抽出した構造化ノート**を日本語で生成する。

## 使うタイミング
- ユーザーが YouTube の URL を貼って要約・ノート化・要点抽出を求めたとき。
- 日本語動画が主対象だが、字幕がある動画なら言語を問わず動作する
  （日本語字幕が無ければ元言語を取得し、可能なら日本語へ翻訳する）。

## 入力
**URL のみ**でよい。ユーザーが言語や出力先を指定した場合のみ、それを尊重する。

## 手順

### 1. 依存関係を確認（初回のみ）
```bash
python3 -c "import yt_dlp, youtube_transcript_api" 2>/dev/null || \
  pip install --quiet yt-dlp youtube-transcript-api
```

### 2. 字幕とメタデータを取得
スキルのディレクトリにある取得スクリプトを実行する。出力（Markdown）は
標準出力に表示され、同時に `notes/<video_id>_transcript.md` にも保存される。

```bash
python3 .claude/skills/yt-nihongo-study/scripts/fetch_transcript.py "<URL>" --lang ja
```

- 既定では日本語字幕（`ja`, `ja-JP`）を手動→自動生成の順で探す。
- 日本語字幕が無い場合は、任意言語の字幕を取得し、翻訳可能なら日本語へ翻訳する。
- チャプター（投稿者設定）があれば取得され、構成把握の助けになる。
- 標準出力に出た「タイムスタンプ付き字幕」を読んで内容を把握する。

失敗した場合（字幕が無効な動画など）は、`--lang en` 等で再試行するか、
ユーザーにその旨を伝える。

### 3. 要点を抽出してノートを作成
取得した字幕を読み込み、`references/note-template.md` の形式に従って
**日本語の学習ノート**を作成する。テンプレートを読んでから書くこと。

要約の原則:
- **書き起こしではなく要約**。冗長表現を削り、主張・根拠・具体例を残す。
- 各要点・引用に `[mm:ss]` のタイムスタンプを付け、動画で確認できるようにする。
- 数字・固有名詞・専門用語は正確に。曖昧なら「（聞き取り不確実）」と注記。
- プレゼン/講義は「結論→根拠→具体例」、解説は「手順・因果」を意識して構造化。
- 話者自身の主張と、引用された他者の意見を区別する。

### 4. ノートを保存して提示
完成したノートを `notes/<video_id>_note.md` に保存し、チャットにも要点を提示する。
`<video_id>` は URL 内の動画ID（`transcript.md` のファイル名と揃える）。

## 出力先
- `notes/<video_id>_transcript.md` … 取得した字幕（自動保存）
- `notes/<video_id>_note.md` … 完成した学習ノート

## 補足
- 長い動画では字幕が数百セグメントになる。全体を読んでから要約する。
- ライブ配信・ショート・`youtu.be` 短縮URL・`/shorts/` などの形式にも対応。
- 字幕が全く無い動画は要約できない。その場合はユーザーに伝える。
